# DeSN – Decentralized Social Network

DeSN is a decentralized, privacy-focused social networking prototype developed as part of my Master's thesis. Instead of relying on a central server, users run their own agents that store and exchange data directly with each other.

This repository contains API documentation for DeSN's core endpoints, written as a technical writing sample.
